# 视觉参数

以本次课堂演讲的视觉体系为起点，按用户参考调整。参数是起点，不要为了固定模板牺牲信息。

| 项目 | 参数 |
|---|---|
| 画布 | 1280×720，16∶9 |
| 背景 | `#000000` 或接近纯黑 |
| 常规文字 | `#F5F5F7` |
| 次要文字 | `#B8B8BE` |
| 辅助说明 | `#94969D`，投影不清楚时提高亮度 |
| 强调色 | `#B3A1FF` |
| 标题渐变 | 水平 `#7197FF` → `#B68BEA` → `#ED6AAB`，位置 0 / 47% / 100% |
| 数字金色 | `#FFE19A` → `#DFAE43` |
| 安全边距 | 左右约 64px，顶部约 48px |
| 中文字体 | 面向 Windows：Microsoft YaHei；确有字体约束时遵从约束 |

`artifact-tool` 的数值字体大小是 CSS px，1pt≈1.333px。参考页标题用 49–61px，主数字 90–148px，正文 28–36px，照片说明 20–24px。勿把这些数值直接当成 PowerPoint 的 pt。照片说明太长时缩短措辞或换行，避免缩小到投影看不清。

## 页面组织

- 开场：主题和真实证据同屏。一个问题即可，不增加空洞独立封面。
- 数字页：一个大数字、统计口径和一幅相关照片。把口径说明保留在可见文字或口播中。
- 证据页：一张主图，必要时两张可比较照片。保留文献照片的关键细节，不能为了布局裁掉证据。
- 时间或因果页：让日期和结论承载叙述，避免连续卡片、徽章、图标网格。
- 结尾页：回扣开场的人、物或问题。可复用开场照片形成叙事回环；新增照片必须核对真实场景。主题和结尾句分阶段出现。

控制可见字量，把完整段落放讲稿和备注。渐变用于少量关键文字，其余文字提供清晰层次，不要全页彩色。标题中的渐变应跨越实际字宽，避免用巨大空文本框稀释色彩。保持可编辑，不以图片模拟文字渐变。

## 讲稿同步

同一张表同时驱动备注和动画：`初始可见`、`点击1`、`点击2`。不要写完讲稿后另编一套幻灯片顺序。结尾页提前纳入时间预算，最后的致谢只说一次。照片说明描述人物、地点、年代；来源与许可按素材要求放备注或备查页。
